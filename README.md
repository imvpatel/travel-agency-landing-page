# Travel Agency Landing Page

A basic HTML landing page for a fictional travel agency. This page features:

- An engaging headline and introduction
- Travel package options
- Stunning imagery with captions
- Clean, semantic HTML structure

## 💡 Features

- Pure HTML
- External image links
- Accessible and semantic tags
- Ideal for HTML/CSS beginners
